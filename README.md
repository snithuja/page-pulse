\# Page Pulse - URL Auditor



> A web tool that audits any URL and provides SEO metrics. Built for the Digital Heroes Training Task.



\## 🚀 Live Demo



\- \*\*Frontend:\*\* https://willowy-sunflower-9e2e86.netlify.app

\- \*\*Backend API:\*\* https://page-pulse-api-qht6.onrender.com

\- \*\*GitHub:\*\* https://github.com/snithuja/page-pulse



\## 📋 Features



\- ✅ \*\*HTTP Status\*\* - Check if the page loads successfully

\- ⏱️ \*\*Response Time\*\* - Measure how fast the page loads

\- 📝 \*\*Page Title\*\* - Extract the page title

\- 📄 \*\*Meta Description\*\* - Check for SEO description

\- 🔢 \*\*H1 Count\*\* - Count heading tags

\- 🖼️ \*\*Images Missing Alt\*\* - Check accessibility

\- 📊 \*\*Word Count\*\* - Count words on the page

\- ⚠️ \*\*SEO Warnings\*\* - Suggestions for improvement

\- 🛡️ \*\*Error Handling\*\* - Graceful handling of failures
